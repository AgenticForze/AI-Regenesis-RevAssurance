# Glossary

| Term | Meaning |
| --- | --- |
| Break | A record or group that fails a reconciliation control |
| Control | A versioned comparison between sources (C1-C9) |
| Tolerance | Allowed difference before a break is raised |
| Leakage | Revenue earned but not billed or collected |
| Overbilling | Amount billed above contract or usage |
| Exception group | Breaks sharing a group_key, investigated once |
| Auto-close | Case closed by the system without analyst review (R3 only) |
| Bolt | A delivery loop of hours to two days for one task |
| Gold set | Analyst-confirmed labeled cases used for evals |
| Held-out set | Gold cases nobody tunes on; used once per release candidate |
| Release manifest | Immutable list of versions that make up a release |
| S1-S10 | Source systems: mediation, rating, billing A, billing B, CRM, orders, catalog, payments, ERP, partners |
